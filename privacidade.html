Política de privacidade

Atualizada em 21 de novembro de 2026.

Esta ferramenta é de uso interno. Ela só é autorizada pelo dono dos canais, nas contas dele, pra enviar vídeos, agendar publicações, gerenciar legendas e playlists e ler as estatísticas desses mesmos canais pela API do YouTube.

O que é acessado

Só os dados dos canais do próprio dono: vídeos, legendas, playlists e estatísticas. A ferramenta não acessa dados de outras pessoas, não vende, não compartilha e não usa esses dados pra publicidade.

Onde fica guardado

A autorização fica salva só no computador do dono. Nada é enviado pra servidor de terceiros além da própria API do Google.

Como revogar

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Contato

Pelo e-mail de suporte que aparece na tela de autorização do Google.
